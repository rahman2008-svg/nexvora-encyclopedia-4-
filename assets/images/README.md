# NexVora Encyclopedia — Image Asset Repository

Store all offline article images and illustrations here.

## Directory Structure

```
assets/images/
├── science/       # Physics, chemistry, astronomy, biology diagrams
├── history/       # Historical monuments, maps, archives
├── geography/     # Rivers, mountains, geographical landscapes
├── biography/     # Portraits of scientists, leaders, writers
├── animals/       # Wildlife and marine life photos
├── technology/    # Computer architectures, hardware, diagrams
├── bangladesh/    # National heritage, monuments, districts
├── environment/   # Ecosystems, climate diagrams, renewable energy
├── space/         # Planets, celestial bodies, galaxies
├── sports/        # Traditional games, sports icons
├── arts/          # Paintings, sculptures, architecture
├── plants/        # Flora, trees, botanical illustrations
└── general/       # Miscellaneous illustrations
```

## Referencing Images in Markdown
In your article Markdown file:
```markdown
![ছবি পরিচিতি ও ক্যাপশন](assets/images/science/atom_model.png)
```

> **Note:** The application handles missing or unavailable images gracefully using placeholders without crashing.
